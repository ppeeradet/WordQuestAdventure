# Word Quest Adventure — Game Design v1 และสถานะ

เกมเว็บใหม่แยกจาก PetRescue สำหรับเด็กเรียนคำศัพท์อังกฤษในวงเล็ก เล่นด้วยชื่อเดียวบนอุปกรณ์ต่าง ๆ โดยไม่ใช้รหัสผ่าน ใครทราบชื่อก็เข้าความก้าวหน้าของชื่อนั้นได้

## การเล่นและหน้าจอ

ชื่อผู้เล่น → แผนที่ 10 โลก × 10 ด่าน → ภารกิจสุ่ม 10 ข้อ → ผลลัพธ์/ช่วยสัตว์/ไข่ → แผนที่, คอลเลกชัน 100 ตัว หรืออันดับ ด่านที่ผ่านแล้วเล่นซ้ำได้ บอสทุกด่านที่ 10 ต้องตอบถูกอย่างน้อย 7/10 จึงเปิดด่านถัดไป; แพ้ไม่เสียสัตว์หรือพลังไข่

โจทย์หกแบบ: Meaning (อังกฤษ→ไทย), Reverse (ไทย→อังกฤษ), Context (เติมประโยค), Spelling/Hangman (กดตัวอักษรที่หายไป, พลาดได้ 5 ครั้ง), Sentence Quest (วิเคราะห์ประโยคและพิมพ์คำ), Listening (ฟังแล้วเลือกคำ) รอบหนึ่งรับประกันโจทย์จากทั้งหกแบบ แล้วสุ่มเติมให้ครบสิบ พร้อมนำคำที่ตอบผิดกลับมาทบทวน แรก ๆ จำกัดชุดระดับ Pre-A1/A1; หลังด่าน 50 เพิ่มคำท้าทายอีกระดับ ระบบสุ่มลดโอกาสรอบติดกันซ้ำทั้งชุด แต่ไม่รับประกันว่าไม่มีข้อซ้ำ

Sentence Quest คงตัวอย่าง `It is important to be ____ and help others.` มีเสียงอ่านประโยค และคำใบ้ ตัวแรก −5, สระ −10, แปล −15 จากคะแนนคำถาม 30 เสียง Listening ใช้ Web Speech ของอุปกรณ์ จึงขึ้นกับภาษา/เสียงที่เบราว์เซอร์รองรับและการตั้งค่าเครื่อง ไม่ใช่ไฟล์เสียงบันทึกแยก

ภาพสัตว์ 100 ช่องใน sprite sheets สี่ชุด (ป่า, น้ำ, ฟ้า/หิมะ, จินตนาการ) แต่ละตัวมีชื่อ ชนิด นิสัย และเรื่องสั้นของตนเอง เริ่มด้วยเพื่อนตัวที่ 1; ชนะภารกิจจะปลดล็อกตัวต่อไปและแสดงป๊อปอัปสัตว์ใหม่ทันที ไข่ได้พลัง 20 ต่อภารกิจสำเร็จ; ทุก 100 พลังฟักสัตว์ Mythic ที่ยังไม่ได้จากกลุ่ม #76–100 หากมีเหลือ เมื่อสะสมครบแล้วไข่ยังฟักแต่ไม่ให้สัตว์ซ้ำ

## เนื้อหาและคุณภาพ

ชุดเพิ่ม 108 คำระดับ Pre-A1/A1 พร้อมคำแปลและประโยคต้นฉบับ แปลงเป็นโจทย์ 648 แบบ รวมกับคำและโจทย์เดิมของเกมใหม่ ตรวจโดยอัตโนมัติว่ามีคำตอบและตัวลวงไม่ซ้ำ และประโยคมีช่องว่างหนึ่งแห่ง อ้างอิงแนวระดับ/หมวดจาก [Cambridge Young Learners 2025](https://www.cambridgeenglish.org/images/506166-starters-movers-flyers-word-list-2025.pdf) และ [British Council LearnEnglish Kids](https://learnenglishkids.britishcouncil.org/grammar-vocabulary/word-games) คำว่า “มักตอบผิด” ในเกมหมายถึงคำที่ผู้เล่นคนนั้นตอบผิดจริง ไม่ใช่สถิติข้อสอบไทย; ยังต้องให้ครูตรวจทานเชิงการสอนและทดสอบกับเด็กก่อนใช้ประเมินผล

## ข้อมูลและเทคนิคที่ใช้งานจริง

- `localStorage` จำชื่อ, XP, ดาว, คำที่ตอบผิด, ด่าน, ไข่ และสัตว์; service worker เก็บ app shell/ภาพไว้ใช้ซ้ำ
- Firebase Anonymous Auth และ Firestore `players/{normalizedName}`: อ่านข้อมูลชื่อเดิมและบันทึก progress เมื่อการเชื่อมต่อและกฎอนุญาต; อันดับอ่านจากข้อมูลผู้เล่นจริง ไม่มีอันดับสมมติ
- GitHub Pages ให้บริการไฟล์คงที่ใน `dist/`; responsive touch-first บนโทรศัพท์, แท็บเล็ตและคอมพิวเตอร์ มีปุ่มสัมผัสและคีย์บอร์ดสำหรับ Sentence Quest
- ไม่มี server ตรวจคะแนน, transaction ป้องกันชื่อชน, sync conflict, IndexedDB event queue หรือ Firebase Functions ในเวอร์ชันนี้ จึงยังไม่ควรเปิด Firestore เขียนสาธารณะโดยไม่ตกลงเรื่องความเสี่ยง
- หาก Firestore ปิดหรือออฟไลน์ เล่นและบันทึกได้เฉพาะเบราว์เซอร์นั้น การเล่นข้ามเครื่องและอันดับกลางจะยังไม่ทำงาน

## โครงสร้างและขั้นต่อไป

`dist/index.html` และ `styles.css` เป็น UI, `app.js` เป็น flow/UI และบันทึก, `pets.js` เป็นสัตว์, `primary-vocab.js` เป็นคำศัพท์, `question-bank.js` สร้าง/ตรวจโจทย์, `progression.js` ตรวจปลดล็อก/บอส/ไข่, `sw.js` เป็น PWA cache, `tests/progression.test.mjs` เป็น regression tests. รัน `npm test` เพื่อตรวจเนื้อหาและกฎ 100 ด่าน

ก่อนเผยแพร่ให้เล่นข้ามเครื่อง ต้องกำหนดนโยบายชื่อซ้ำ/การเข้าถึง, กฎ Firestore และวิธีป้องกันแก้ XP/อันดับจาก client; จากนั้นทดสอบ Firebase จริง, มือถือ/iPad และ deploy repository ใหม่ไป GitHub Pages จึงจะมีลิงก์สาธารณะได้
